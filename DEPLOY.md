# Деплой на Cloudflare Pages

## Подключение (один раз, через дашборд — токены не нужны)

Workers & Pages → Create → Pages → Connect to Git → выбрать репозиторий.

| Поле | Значение |
|---|---|
| Framework preset | None |
| Build command | `npm run build` |
| Build output directory | `web/dist` |
| Root directory | `web` |

Переменные окружения:

```
BASE_PATH = /
VITE_DATA_BASE = https://data.<домен>/        # когда данные уедут в R2
VITE_ANALYTICS_URL = https://<аналитика>/api/event   # необязательно
VITE_TIPS_URL = https://pay.cloudtips.ru/p/<твой-код>  # без неё блок кофе скрыт
```

`BASE_PATH=/` обязателен: по умолчанию сборка настроена на подпапку
`/dtp-analitycs/` для зеркала GitHub Pages.

## Что появляется автоматически

Файлы в `web/functions/` Pages подхватывает сам, отдельного деплоя не нужно:

| Путь | Что делает |
|---|---|
| `/api/geo` | координаты запроса из `request.cf` для подсказки региона |
| `/og?kind=…` | картинка 1200×630 для превью ссылки |
| `_middleware.js` | подставляет OG-теги в index.html под конкретную ссылку |

## Проверка после деплоя

1. Открыть `/route?a=54.9885,73.3242,Омск&b=54.9136,71.2685,Исилькуль` —
   отчёт должен собраться сам, без нажатия кнопки.
2. Открыть `/og?kind=fleet&brand=ВАЗ&vs=TOYOTA` — должна отдаться картинка.
3. Кинуть ссылку из п.1 в Telegram — развернётся карточка с числом ДТП.
4. Зайти с телефона на `/` — через секунду появится плашка с регионом.

Если п.3 не сработал, Telegram кэширует превью: сбросить через @WebpageBot.

## Зеркало GitHub Pages

`deploy.yml` продолжает работать без изменений и собирает с
`BASE_PATH=/dtp-analitycs/`. Функций там нет, поэтому на зеркале не будет
OG-картинок и подсказки региона — приложение это переживает молча,
ошибок не показывает.

## Данные в R2 (когда дойдут руки)

Сейчас 82 МБ данных коммитятся в репозиторий каждую неделю — за год
история раздуется до десятков гигабайт. Схема переезда: залить
`web/public/data/` в бакет, повесить публичный домен, выставить
`VITE_DATA_BASE`. Токен для еженедельной заливки — узкий, только на
запись в один бакет, и хранится в GitHub Actions Secrets.

## Кофе

Ссылка задаётся переменной `VITE_TIPS_URL`. Без неё блок просто не
показывается — ничего не ломается.

Счётчик читает `web/public/data/support.json` и **обновляется вручную**.
Если поле `updated` старше 45 дней, счётчик прячется сам: протухшее
«собрано 0 ₽» выглядит хуже, чем его отсутствие.

В самом CloudTips имеет смысл включить «Цель» в выпадающем списке суммы —
тогда прогресс виден и на странице оплаты, а не только у нас.
